# 🎓 StudentHub Portal

A responsive academic portal developed using HTML and CSS.

---

## 📖 About

StudentHub Portal is a centralized website where students can access academic information such as:

- Student Dashboard
- Courses
- Timetable
- Notices
- Profile
- Login & Registration

---

## 🚀 Features

- Responsive Design
- Simple Navigation
- Student Dashboard
- Course Information
- Notice Board
- Profile Management
- Login/Register Pages

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Git
- GitHub
